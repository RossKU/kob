# Prototypes: NOT DEPLOYED

Nothing under `contracts/prototypes/` is KOB production code. Do not audit it as such: the deployed order contracts
are `contracts/orders/` and `contracts/orders/kron/` (see `contracts/README.md`, "What is deployed / what to audit").

| Path | What |
|---|---|
| `kcc20/variants/KCC20Ref_*.sil` | The reference KCC-20 token with other per-transaction slot limits (4/5, 8/8, 16/16), generated by `kob_protocol::kcc20::kcc20_source_with_limits`. Not used for issuance; `KCC20Ref_8x8` stays pinned so that the testnet tokens issued with it remain tradable |
| `kcc20/p2/` | Proposal P2 (`KCC20P2`, `KCC20Batch`) and the optional batch-leader holder `KCC20Opt` (the upstream proposal was withdrawn; KOB uses the standard 3/3). Tested, not used for issuance |

The sources are still compiled by `scripts/build-contracts.sh` (their artifacts are in `contracts/artifacts/`) and
tested, so they cannot rot. The generated sources are checked byte for byte against their generators, which is why
they carry no "not deployed" header of their own.
